## Как читать цену

Сначала евро, потом центы. Слово *Cent* обычно не говорят.

| Пишем | Говорим |
|---|---|
| 0,99 € | neunundneunzig Cent |
| 1,60 € | ein Euro sechzig |
| 3,20 € | drei Euro zwanzig |
| 8,60 € | acht Euro sechzig |
| 40,50 € | vierzig Euro fünfzig |

## Вопросы о цене

- *Was kostet das Brot?* / *Wie viel kostet das Brot?* — Сколько стоит хлеб?
- *Was kosten die Äpfel?* — мн. число: ***kosten***.
- *Das macht 8,60 Euro.* — С вас 8,60 евро.
- *Das ist teuer / billig / günstig.* — Это дорого / дёшево / недорого.

## Количество

| Немецкий | Значение |
|---|---|
| ein Kilo Äpfel | килограмм яблок |
| ein Pfund Tomaten | фунт (500 г) помидоров |
| 250 Gramm Käse | 250 г сыра |
| eine Flasche Wasser | бутылка воды |
| ein Liter Milch | литр молока |
| zwei Stück Kuchen | два куска пирога |
| ein halbes Brot | полбуханки хлеба |

После меры продукт стоит без артикля и без «из»: *ein Kilo Äpfel* (не *von Äpfeln*).

## Диалог в булочной (Folge 50)

- *Ich hätte gern ein Brot. Was kostet das Roggenbrot?* — *3,20 Euro.*
- *Und ein halbes?* — *Ein halbes Roggenbrot kostet 1,60 Euro.*
- *Darf es sonst noch etwas sein?* — *Ich hätte gern noch zwei Stück Apfelkuchen.*
- *Das macht dann 8,60 Euro.* … *Und 1,40 zurück.* — сдача 1,40.

*Ich hätte gern …* — «Я бы хотел(а) …». Это очень вежливая форма. Учите как фразу.
